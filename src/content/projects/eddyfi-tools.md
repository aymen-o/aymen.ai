I built Eddyfi’s public tools for configuring non-destructive testing probes. The Tubing Probe Creator matches tube material, outer diameter, and wall thickness to probe configurations, with fill factor and cable options. The PAUT Probe Finder handles frequency, element count, and array geometry, then pairs probes with compatible wedges. Both carry the selection into a quote request.
